# 🛰️ Экосистема аналитики Ростовской области

Интерактивная платформа для гео-аналитики, инвестиционного планирования и экспресс-оценки проектов цифровизации на территории Ростовской области.

---

## 🚀 Модули экосистемы

1. **Радар присутствия (Гео-аналитика)**  
   Интерактивная карта с фильтрами по отраслям и выручке. Автоматический поиск «белых пятен» — зон с высоким потенциалом и нулевым покрытием РТК.

2. **Инвестиционный навигатор**  
   Таймлайн инвестиционных проектов Ростовской области с фильтрами по стадиям (проектирование, стройка, запуск) и потребностям в цифровизации.

3. **Калькулятор сделок**  
   Экспресс-оценка стоимости проекта на основе исторических данных (KNN-подбор аналогов). Учитывает региональные коэффициенты, срочность и уровень сложности.

## 📊 Реальные данные (Data Engineering)

В основе проекта лежат **реальные данные** Ростовской области:

- **54 компании** — выгрузка ФНС с валидными ИНН и ОКВЭД
- **30 инвестиционных проектов** — реестр инвестпортала
- **20 исторических сделок-бенчмарков** — для KNN-подбора в калькуляторе
- **4 «белых пятна»** — Порт, Батайск, Новый Аксай, Таганрог-Пром

> 💡 *Исходные Excel/Word файлы находятся в папке `backend/data/source/`.*

## 📦 Как запустить проект локально

### 1. Бэкенд (FastAPI)

Перейдите в папку бэкенда, установите зависимости и запустите сервер:

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

> 💡 **Важно:** База данных SQLite и фикстуры (реальные компании и проекты) загрузятся автоматически при первом запуске сервера. Вам не нужно настраивать БД вручную.

Интерактивная документация API (Swagger) будет доступна по адресу:  
👉 [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

### 2. Фронтенд (React)

Откройте **новый терминал** (не закрывая бэкенд) и запустите интерфейс:

```bash
cd frontend
npm install
npm run dev
```

## 🧠 Архитектурные решения

- **Двухформатный калькулятор** — API принимает как параметры фронтенда (`object_type`, `scale`), так и прямые параметры бэкенда (`scale_param`).
- **KNN-подбор аналогов** — калькулятор автоматически находит 3 ближайших проекта по масштабу и отрасли из базы бенчмарков.
- **Методика расчёта** — используются формулы ПИР (10%), ПНР (15%), Шеф-монтаж (5%) от стоимости оборудования (согласно методичке Ростелекома).
- **Масштабируемость** — скрипт `parse_excel.py` позволяет распарсить выгрузку ФНС любого региона РФ за ~15 минут (достаточно поменять `REGION_CODE`).
