## 6. Масштабируемость (тезис для слайда)

Пайплайн не привязан к региону. За счёт генератора ИНН по алгоритму ФНС и параметризованных кластеров данные любого субъекта РФ можно подставить за ~15 минут.

В `backend/app/logic/data_generation.py` регион задаётся кодом:

```python
REGION_CODE = "61"  # Ростовская область
```

Константы, которые нужно поменять для другого региона:

| Константа | Текущее значение | Для нового региона |
|-----------|-----------------|-------------------|
| `REGION_CODE` | `"61"` | код региона по ОКАТО/ФНС |
| `REGION_COEFFS["61"]` | `1.00` | региональный коэффициент |
| `CLUSTER_ZONES_SPEC` | 9 зон Ростовской обл. | список зон нового субъекта |
| `ANCHOR_COMPANIES` | 8 ростовских игроков | локальные якорные компании |
| Координаты (lat/lon) | Ростов-на-Дону | центр нового региона |

Генератор ИНН использует контрольную сумму ФНС (веса [2,4,10,3,5,9,4,6,8] для 10-значных ИНН), которая одинакова для всех регионов РФ — достаточно сменить префикс кода региона (первые две цифры).

> **Почему ручные кластеры, а не DBSCAN/K-Means:** для хакатон-демо важна интерпретируемость зон для менеджеров продаж (названия «Порт», «Батайск», «Таганрог-Пром» понятны без объяснений), а не геометрическая кластеризация.
