## 4. Методология калькулятора

### Коэффициенты структуры затрат

| Затраты | Процент от цены | Описание |
|---------|-----------------|----------|
| **ПИР** (Производственно-инженерные издержки) | 10% | Расчетные затраты на проектирование, инженерную подготовку и überwachung works |
| **ПНР** (Производственно-на ремонтные) | 15% | Затраты на основные работы по монтажу и установке |
| **Шеф-монтаж** | 5% | Надзор и координация работ главным montazhem в ходе проекта |
| **Базовые затраты** | 70% | Материалы, оборудование, оборудование |

### Коэффициенты сложности проекта

| Уровень сложности | Коэффициент | Описание |
|-------------------|-------------|----------|
| **Basic** | 1.0 | Стандартные проекты, типы зданий, однозначные требования |
| **Advanced** | 1.3 | Сложные объекты, частичная специализация, дополнительные требования |
| **Expert** | 1.6 | Уникальные проекты, высокая специфика, строгие нормы и стандарты |

Формула расчета:
```
cost_price = base_cost × (1 + ПИР/100 + ПНР/100 + Шеф-монтаж/100) × difficulty_coeff
min_price = cost_price × 1.15
optimal_price = cost_price × (1 + margin_percent/100)
```

## 6. Масштабируемость

Пайpline позволяет распарсить Excel-выгрузку ФНС любого региона РФ:

- Генератор ИНН использует контрольную сумму ФНС (веса [2,4,10,3,5,9,4,6,8] для 10-значных ИНН), которая одинакова для всех регионов РФ — достаточно сменить префикс кода региона (первые две цифры).
- `REGION_CODE = "61"` — код Ростовской области по ОКАТО/ФНС.
- Для нового региона достаточно изменить:
  - `REGION_CODE` — код нового региона.
  - `REGION_COEFFS` — региональные коэффициенты.
  - `CLUSTER_ZONES_SPEC` — список зон нового субъекта (заменяет 9 зон Ростовской обл.).
  - `ANCHOR_COMPANIES` — якорные компании нового региона (заменяет 8 ростовских игроков).
- Координаты (lat/lon) устанавливаются в центре нового региона.
- Вся схема работает за ~15 минут на генерацию полного датасета.

> **Почему руные кластеры, а не DBSCAN/K-Means:** для хакатон-демо важна интерпретируемость зон для менеджеров продаж (названия «Порт», «Батайск», «Таганрог-Пром» понятны без объяснений), а не геометрическая кластеризация.
